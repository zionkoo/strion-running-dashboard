# STRION

Garmin 원본 `.fit` 러닝 파일을 브라우저에서 직접 분석하는 정적 웹 대시보드입니다.

## 브랜드 의미

`STRION`은 `STRIDE + ON`의 합성어입니다. 한 걸음의 데이터를 분석해 더 나은 다음 걸음으로 계속 나아간다는 의미를 담았습니다.

## 주요 기능

- 거리, 시간, 평균 페이스, 평균·최대 심박, 케이던스, 상승 고도, 칼로리 요약
- 페이스, 심박, 케이던스, 고도 시간축 그래프
- FIT Lap 데이터 또는 기록 데이터를 이용한 구간 분석
- 최대 심박 기준 심박 구간 분포
- GPS 데이터가 있을 때 외부 지도 요청 없는 로컬 경로 스케치 표시
- 파일에 포함된 러닝 파워 및 러닝 다이나믹스 자동 표시
- 개인 PB, 대회 일정, D-day 및 목표 페이스 관리
- 이븐·네거티브·포지티브 레이스 전략과 1km 목표 스플릿 생성
- 운동 일정 등록 및 완료 상태 관리
- 거리별 평균·최대 심박과 심박 급상승 페이스 분석
- FIT 원본과 분석 요약의 브라우저 저장, 날짜 선택 재열람
- 최근 8주 거리·횟수 그래프
- PB 기반 추정 VDOT 및 E·M·T·I·R 참고 페이스
- 업로드한 훈련을 현재 체력 기준으로 비교하는 STRION Coach 분석
- Garmin 워크아웃 이름과 인터벌 랩 자동 인식
- FIT 파일을 외부 서버로 전송하지 않고 브라우저 안에서 분석·보관

## 실행

로컬에서는 `index.html`을 직접 열거나 간단한 정적 웹 서버로 실행합니다. 인터넷 연결은 Garmin FIT SDK와 Chart.js를 불러올 때 필요합니다. GPS 경로는 외부 지도 서버를 사용하지 않습니다.

## 배포

이 폴더의 `index.html`, `styles.css`, `app.js`를 새 GitHub 저장소 루트에 업로드한 뒤 GitHub Pages를 `main / (root)`로 설정하면 됩니다.

## 사용 라이브러리

- Garmin 공식 JavaScript FIT SDK
- Chart.js

FIT 파일에 기록되지 않은 센서 항목은 화면에 표시되지 않습니다. 칼로리는 FIT에 포함된 기기 계산값을 사용하며 별도로 추정하지 않습니다.
